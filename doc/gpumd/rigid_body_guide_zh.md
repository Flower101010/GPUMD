# 刚体模拟使用说明与注意事项

本仓库支持由多个 bead 组成的非线性刚体，并允许与自由粒子混合。
刚体在原子势（包括温度无关的 NEP）提供的 bead 受力下平动、转动，
内部几何保持不变。不同刚体可以有不同数量的 bead；主要面向大量小刚体。

## 准备分子分组与速度

复用 GPUMD 的分组系统表示刚体。在 `model.xyz` 的 `Properties` 中
提供 `group:I:1`，同一个标签表示同一分子的所有 bead。例如：

```text
4
Lattice="30 0 0 0 30 0 0 0 30" pbc="T T T" Properties=species:S:1:pos:R:3:group:I:1
C 10.0 10.0 10.0 0
C 11.0 10.0 10.0 0
C 10.3 10.8 10.0 0
C 15.0 15.0 15.0 1
```

前三个 bead 构成一个三成员刚体，最后一个是自由粒子。
**XYZ 分组标签必须是非负整数，且小于总原子数；不要在输入文件中写 `-1`。**
每个自由粒子必须有独立标签，否则同标签的多个粒子会被视作一个刚体。
分组方法索引从 0 开始；上例只有一种分组方法，选择 `0`。
应选择表示分子归属的分组，而不是物种或温控区域分组。
示例中的元素、盒子和坐标仅说明格式，实际体系需要匹配的势文件。

初始化时，刚体应足够紧凑，在每个周期方向上的一致展开跨度小于半盒长。
当前不支持线性、近线性、重合或其他退化刚体。
初始 bead 速度会投影为刚体平动和转动，**不会自动重标定到目标温度**。
可以在 `model.xyz` 中提供 `vel:R:3`（Å/fs），或按 GPUMD 的
[velocity 命令](input_parameters/velocity.rst)生成速度。
若文件已含速度，`velocity` 命令不会覆盖它们；投影后应检查实际动温度。
`ensemble` 中的初始温度是热浴目标，不是速度初始化指令。

## 选择系综

| 系综 | 命令 | 盒子与目标要求 |
| --- | --- | --- |
| NVE | `ensemble rigid_nve grouping_method` | 固定盒，支持现有周期盒几何 |
| NVT | `ensemble rigid_nvt T_initial T_final T_coupling grouping_method` | 固定盒；允许目标温度线性变化 |
| NPT | `ensemble rigid_npt T_initial T_final T_coupling P P_coupling grouping_method` | 三维全周期正交盒，各向同性伸缩；两项温度必须相同，目标压力恒定 |

NVT 使用独立的平动链和转动链，与 NPT 共用恒温链推进实现。
平动链同时控制自由粒子和刚体质心，转动链控制刚体旋转；没有刚体时跳过转动链。
NPT 另有活塞链和各向同性 MTK 压力耦合。
当前每条链为 10 节，链积分为 1 次子循环，使用三段 Yoshida 权重；
`run.in` 尚不开放链长、子循环次数或分裂阶数选项。
普通 `nvt_nhc` 或其他软件的附加参数不能直接附在这些命令后面。

## 温控、压控参数与时间步长

| 参数 | 单位和含义 |
| --- | --- |
| `time_step` | 积分步长，fs；同一次刚体 `run` 内必须固定且为正 |
| `T_initial`, `T_final` | 目标温度，K，必须为正且有限；NPT 要求二者相等 |
| `T_coupling` | 温控耦合步数，有限且至少为 1 |
| `P` | 目标静水压力，GPa；正值表示压缩压力，1 bar = 0.0001 GPa |
| `P_coupling` | 压控耦合步数，有限且至少为 1；NPT 不需要弹性模量参数 |

实际耦合时间为：

```text
tau_T (fs) = T_coupling * time_step
tau_P (fs) = P_coupling * time_step
```

coupling 不是 fs，也不是缩放系数或输出间隔。改变步长时，若希望保持相同的
物理耦合时间，应同时改变这两个步数参数。例如保持 `tau_T=100 fs`、
`tau_P=1000 fs`，并每 10 fs 输出一次 thermo：

| 步长 (fs) | `T_coupling` | `P_coupling` | `dump_thermo` 间隔 (步) |
| --- | --- | --- | --- |
| 0.05 | 2000 | 20000 | 200 |
| 0.5 | 200 | 2000 | 20 |
| 1 | 100 | 1000 | 10 |
| 2 | 50 | 500 | 5 |

这是单位换算表，不代表每种步长都具有足够精度。这些耦合时间是本仓库混合体系
测试采用的设置，不能作为所有 NEP 或材料的通用最优值。

耦合时间是扩展系统的特征时间，不保证体系在该时间内完成平衡。
较短耦合时间使反馈更强，也可能使链或活塞难以稳定积分；较长耦合时间则会减慢
温度、压力响应。它不能替代构型弛豫、充分采样和步长收敛检查。
特别是**温度均值持续偏离目标时，应先检查动能时间层、自由度和步长收敛**，
不要通过提高目标温度来补偿偏差。

### 输入示例

以下使用同一份含合理初始坐标和速度的 `model.xyz`：

```text
potential nep.txt
time_step 0.5
ensemble rigid_npt 300 300 200 0.0001 2000 0
dump_thermo 20
dump_xyz 4000 trajectory.xyz precision double mass velocity force potential group_labels
run 400000
```

总时长为 200 ps，目标为 300 K、1 bar，温控和压控耦合时间分别为 100 fs、1 ps。
输出间隔分别为 10 fs、2 ps。使用 NVT 时，将系综命令换为
`ensemble rigid_nvt 300 300 200 0`；使用 NVE 时换为 `ensemble rigid_nve 0`。
这些参数和时长需要在实际体系上重新验证。
详细输入语法见 [ensemble 命令](input_parameters/ensemble_standard.rst)。

## 初态准备、平衡与步长验证

1. 从几何合理、无严重近距离接触的构型开始。已有合适的平衡帧可以复用，但应保留
   盒子、质量、分组和刚体相容的速度，并记录来源。降低速度不能消除构型储存的势能。
2. 必要时用较小步长 NVT 弛豫温度和结构。NVE 可用于检查能量漂移，本身不散热，
   不能保证从高势能初态得到低温平衡构型。
3. NPT 运行中同时观察温度、静水压力、体积/密度和结构。压力均值接近目标时，
   体积仍可能缓慢漂移；不能仅按若干个 coupling 时间认定平衡。
4. 在预先确定、确认较稳定的窗口统计，并报告分块误差、漂移和各动能分区。
   若窗口仍不稳定，应补充采样并重新评估，而不是仅调整截断点让结果通过。
5. 使用相同初态、相同物理时长和耦合时间比较不同步长。能够运行而不崩溃，
   不代表温度、密度或结构统计足够准确。

当前分裂中恒温链使用中间时间层动能，thermo/XYZ 使用完整积分步结束后的速度。
有限步长下这两类动能可以不同。测试中 2 fs 出现明显温度偏低，减小到 1 fs、
0.5 fs 后偏差减小。刚体约束去掉内部振动，并未去掉刚体间相互作用的快速变化；
不能仅因使用刚体就假定 2 fs 合适。

遇到 `Rigid NH chain overflow`，应检查最后的温度、势能、体积和非有限值，
核实 coupling 的物理时间，并用较小步长短测定位。该消息只表示链变量发生溢出，
不能单凭它判断是初态问题、参数问题还是实现问题。

## 输出与运行边界

- 温度和动能使用 `f = 3*N_free + 6*N_body`，不自动扣除全体系质心自由度。
  分区温度的自由度为 `3*N_free`、`3*N_body`、`3*N_body`，分别对应自由粒子、
  刚体质心平动和刚体转动。总温度正确不能替代各分区的均分检查。
- `thermo.out` 的静水压力为 `(sxx + syy + szz)/3`，单位 GPa，包含刚体约束贡献。
  XYZ 等输出中的 per-atom virial 只含相互作用，不可直接用来重建完整约束压力。
- 瞬时温度和压力应有涨落，不需要每个采样点都等于目标。瞬时压力可能为负，
  即使目标压力为正。接近零的目标压力应使用绝对误差和分块统计误差评估，
  不宜仅用相对百分比判断控压质量。
- NPT 只伸缩盒子、刚体质心和自由粒子位置；内部距离不随盒子伸缩。
  应用每帧实际盒子对真实笛卡尔距离做最小镜像检查，不能只比较分数坐标。
  需要观察微小变化时使用 `precision double`。
- NVT/NPT 的约束压力使用瞬时机械约束力，不包括恒温器和活塞摩擦冲量。
  物理系统的 `K+U` 在 NVT/NPT 下无需守恒，不应套用 NVE 能量验收标准。
- 不支持 `fix`、`move`、外部 `deform`、自适应步长、`correct_velocity`、
  unwrapped 坐标存储和温度相关势。
- 当前开放 `dump_thermo`、wrapped `dump_xyz`、wrapped `dump_netcdf`（需编译支持）、
  `dump_restart`、`compute_rdf`、`compute_adf`、`compute_angular_rdf`、`compute_orientorder`；
  其他 action 尚未适配。
- 每个新 `run` 都重新构建刚体并重置恒温链，NPT 也重置活塞。
  因此预平衡与生产若拆成两个 `run`，不是连续扩展系统轨迹。
  需要链和活塞连续时，可一次连续运行，再离线丢弃前段数据。
- bead restart 文件不是完整扩展系统检查点。新 `run` 可以修改步长；
  输出命令需按 GPUMD 常规测量生命周期重新设置。

## 当前验证范围

NVE 已有运行与能量守恒检查；独立双链 NVT 已完成混合体系长测和步长对照。
0.5 fs NPT 已完成 200 ps 混合体系长测，温度、压力、体积漂移、动能分区、
刚体几何与静态 NEP 对照通过当前工程验收。

测试使用 C 标记的合成体系：300 个三 bead 刚体和 2700 个自由粒子，共 3600 beads、
9900 个自由度。NVT 在 0.5 fs 时生产均温约 299.82 K；同一起始模型的 NPT
生产均温约 299.50 K，目标压力为 0.0001 GPa，生产均压约 0.00009838 GPa。
这些结果说明该测试配置已通过现有检查，**不等于对任意势、步长、组成或真实材料
平衡密度的保证，也不是完整 NPT 分布正确性的证明**。

测试脚本及结果含义见 [NVT 验证说明](../../tests/gpumd/rigid/scale_validation_NVT/README.md)
和 [NPT 验证说明](../../tests/gpumd/rigid/scale_validation_NPT/README.md)。
长测通过的是预先定义的工程容差；均温在宽容差内也可能存在可测的步长偏差。
正式采样前仍应在自己的体系上确认精度、平衡窗口和统计误差。
