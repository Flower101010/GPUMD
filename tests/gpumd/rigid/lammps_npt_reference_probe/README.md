# LAMMPS / GPUMD 刚体 NVT、NPT 几何对照

这个测试直接运行两个 MD 程序，检查**一个积分步结束、输出轨迹时**三条内部距离是否保持。
当前对照包含 LAMMPS NVT/NPT 与 GPUMD NVT/NPT 各 1000 步；下方保留此前的一步、多版本核验。
本次只增加诊断脚本与记录，没有修改任何生产积分算法。

## 小体系与参数对齐

使用 3 个质量均为 12 u 的 bead 组成边长 **3 Å 的等边三角形**，质心位于 30 Å
全周期正交盒中心。3 Å 相对盒长足够小，避免最小镜像歧义；零模型力使几何变化不会与势能模型混淆。
三角形在浮点坐标中由 `sqrt(3)` 构造，实际初值为 `r12=3.0`、
`r13=r23=3.0000000000000018 Å`，比较的是各自的实际初值。

| 参数 | LAMMPS | GPUMD |
| --- | --- | --- |
| 体系/分组 | 同一组 3 个原子，molecule=1 | 同一组 3 个原子，group=0 |
| 初始坐标与速度 | 共同生成的坐标；速度由 Å/fs 转成 Å/ps | 共同生成的坐标和 Å/fs 速度 |
| 初始运动 | 非零质心速度 + 刚体角速度；平动、转动各约 `3kT/2` | 相同，不做单独 bead 随机赋速或质心清零 |
| 相互作用 | `pair_style zero` | ε=0 的 LJ；同样为零原子力、零模型 virial |
| 积分器 | `rigid/nvt/small` / `rigid/npt/small` | `rigid_nvt` / `rigid_npt` |
| 步长与总时长 | 0.0005 ps，1000 步 = 0.5 ps | 0.5 fs，1000 步 = 500 fs |
| 目标温度 | 300 K | 300 K |
| 温度耦合时间 | 0.1 ps | 200 步 = 100 fs |
| NPT 静水压力 | 1 bar | 0.0001 GPa |
| 压力耦合时间 | 1 ps | 2000 步 = 1000 fs |
| 链参数 | 显式 `tparam 10 1 3`、NPT `pchain 10` | 实现默认：链长 10、1 次子循环、Yoshida 3 项组合 |
| 自由度 | 平动 3 + 转动 3；`thermo_temp extra/dof 0` 避免额外扣除整体平动 | 平动 3 + 转动 3 |
| 保存 | 每 100 步，坐标 `%.17g` | 每 100 步，`precision double` |

LAMMPS 使用 `units metal`，两者基本单位常量的有限精度及压力实现并非逐位相同；
两边恒温链、活塞从各自初始化状态开始。这个测试要求几何保持，**不要求盒长或整条轨迹逐步重合**。
单个无相互作用刚体不是液体模型，0.5 ps 也不足以验收 NPT 分布；这里的合理性限于隔离刚体几何与盒映射。

## 运行与输出

先提供启用了 RIGID 包的 LAMMPS 和已编译的 GPUMD：

```bash
python3 tests/gpumd/rigid/lammps_npt_reference_probe/compare.py \
  --lammps /tmp/gpumd-lammps-stable-2026-build/lmp \
  --lammps-source /tmp/gpumd-lammps-stable-2026 \
  --gpumd build/gpumd \
  --out-dir tests/gpumd/rigid/lammps_npt_reference_probe/results/equilateral_1000 \
  --update-readme
```

上面是本次实际使用的路径，其他机器需替换可执行文件和源码路径。
重新运行请使用新的 `--out-dir`，脚本拒绝向非空目录追加，避免 GPUMD 的旧轨迹混入新结果。
可用 `--side`、`--dt`、`--steps`、`--temperature`、`--pressure`（GPa）、`--tau-t/--tau-p`（fs）调整参数。
`--steps` 必须为 10 的倍数，自动均匀选择 10 个非零步的帧；`--update-readme` 只替换自动结果区。
仅使用 Python 标准库；脚本成功退出要求两边固定盒 NVT 和 GPUMD NPT 的距离误差小于 `1e-10 Å`。
LAMMPS NPT 的距离变化是观察结果，不被设为需要复制的通过标准。

结果目录由 Git 忽略，轨迹保存在本机而不随仓库提交；CSV、JSON、生成输入和日志均可用上面的命令重建。

## 一个积分步的区别：只看外层顺序

两边都用刚体状态（质心、动量、四元数）积分，再重建 bead。
“半步动量更新”是作用力/力矩的 velocity-Verlet 更新；下面把恒温器、活塞链和 MTK
作为整体模块列出，不展开链内部的子步。

**NVT：外层结构一致。** 都是旧力半步更新动量 → 用旧链速率缩放动量 →
推进质心和姿态 → 推进恒温链并重建 bead → 计算新力 →
用新链速率缩放动量 → 新力半步更新动量 → 重建 bead 速度、输出。
LAMMPS 在 `set_xv()` 前更新链，GPUMD 在重建 bead 后更新链；链更新本身不直接重写
bead 坐标，因此这一位置差别不会仿射缩放内部几何。

**NPT：关键区别在坐标推进与盒映射。**

| 顺序 | LAMMPS `FixRigidNHSmall` | GPUMD `Ensemble_Rigid_NPT` |
| --- | --- | --- |
| 1 | 旧力/力矩半步更新动量，然后按恒温器/活塞缩放 | 同样先更新动量，再缩放 |
| 2 | 推进质心（使用活塞修正的漂移系数）与四元数 | 先按 `exp(nu*dt)` 缩放盒及质心，再以相应漂移系数推进质心、四元数 |
| 3 | 推进物理恒温链、活塞恒温链 | 周期映射质心，由最终盒与姿态重建 bead 坐标/速度，再推进两类链 |
| 4 | `remap()` → `set_xv()` → `remap()`：两次半次盒映射夹着一次 bead 重建 | 步骤 2 已完成一次盒缩放；步骤 3 重建后不再仿射缩放成员 bead |
| 5 | 用此时 bead 坐标计算新力 | 用此时 bead 坐标计算新力 |
| 6 | 按新链/活塞速率缩放动量，再以新力/力矩完成后半步，重建速度，更新压力/活塞状态、输出 | 同样先缩放、再完成后半步，重建速度，更新压力/活塞状态、输出 |

在 LAMMPS 指定版本中，两次 `remap()` 每次都用 `exp(nu*dt/2)` 改变盒长并映射
原子坐标；第一次映射后 `set_xv()` 恢复内部几何，第二次映射后本步没有再次重建位置，
`final_integrate()` 中的 `set_v()` 只重建速度。因此最终输出坐标的边长会带有最后这次
映射的比例。下一步会从保存的体内几何重新重建；**这不等于把变形后的边长永久当作新刚体模板累计**。
之前的一步静止测试能直接核对半次盒长比例；本次有转动和长序列，表格只记录实际距离，不额外强设该比例为验收标准。

GPUMD 的受控缩放只改盒、质心与自由粒子坐标，保留体内参考位置；最后用
`r_i = R_cm + A(q) * r_i_body` 重建成员。因此盒会变化，内部边长仍保持在浮点/文本往返误差量级。
单个 `rescale_box()` 不能理解成“少积分半步”，它配合
`R_new = exp(nu*dt)*R_old + expm1(nu*dt)/nu*v` 的完整平动漂移使用。
初始化前置的活塞更新与每步末的活塞更新也已保留；这里不展开其内部算法。

另外，LAMMPS 绕盒中心变盒并改变 `boxlo`，GPUMD 使用零原点盒；这会影响绝对坐标的直接比较，
不会改变同一帧两点之差。本测试直接用 x/y/z 和当帧盒做最小镜像计算，另以
`xs/ys/zs + 当帧盒边界` 和 `xu/yu/zu` 独立核对，未把分数坐标差当距离。

# LAMMPS 刚体 NPT 参考行为核验

这是直接运行 **LAMMPS 可执行程序** 的开发诊断，不运行 GPUMD，也不修改其积分算法。
用于在移植 NPT 盒映射之前确认参考程序的 bead 坐标行为。
工具仅采集观察结果；成功退出不表示某个 NPT 算法通过物理验收。

## 最小体系

- 三个点粒子组成一个非线性三角刚体，初始 bead 1–2 距离为 1 Å。
- `units metal`，质量均为 10，30 Å 全周期正交盒。
- `pair_style zero`：模型力和模型 virial 均为零。
- 默认 bead 初始速度为零，目标温度为 300 K。
- 积分一步，步长 0.001 ps（1 fs），温度/压力耦合时间均为 1 ps。
- 主压力目标 10000 bar（1 GPa），另设 1 bar 和无实际盒变化的对照。

这是隔离几何更新的短测试。零初始速度不能用于证明恒温器的采样能力，
本测试也不以温度平衡、密度或涨落为验收目标。额外的 moving 对照给出
非零统一平动速度，检查观察结果是否只出现在完全静止的初态。

## 重现

提供一个启用 RIGID 包的 LAMMPS 可执行文件：

```bash
python3 tests/gpumd/rigid/lammps_npt_reference_probe/run.py \
  --lammps /path/to/lammps-build/lmp \
  --source /path/to/lammps-source \
  --out-dir tests/gpumd/rigid/lammps_npt_reference_probe/results/my-version
```

`--source` 可选，用于记录完整提交号、源码是否有修改及关键源文件 SHA256。
每次输出包含生成的输入、原始 stdout、LAMMPS dump/log 和 `reference_probe.json`。
JSON 同时记录可执行文件 SHA256、盒长、三条内部距离、几何偏差，以及是否匹配
半次/整次盒长缩放。原始结果目录被 Git 忽略。

需要自行构建参考时，应在独立目录构建，避免改动现有 LAMMPS checkout：

## 检查的参考路径

1. `rigid/nvt/small`：固定盒基线。
2. `rigid/npt/small`：目标 10000 bar、1 bar、0 bar；另有非零初始平动速度对照。
3. `rigid/npt`：检查非 small 版本是否有同样行为。
4. `rigid/nph/small`：排除物理恒温链是唯一成因。
5. `rigid/nve/small` 与空组上的 `fix npt`：检查文档推荐的另一条组合路径，
   同时记录两种 fix 定义顺序是否被接受。

[LAMMPS 官方文档](https://docs.lammps.org/fix_rigid.html)明确介绍了空组上的
恒压器与刚体积分器组合。这里仅检查该组合的几何行为；不将其短时结果
解释为长时间系综正确性的证明。

## 观察结果

具体版本和数值记录在下方。所有比较均为实际编译的、未修改的参考源码。

| 参考版本 | 提交 | NVT 的 r12 / Å | NPT（10000 bar）的 r12 / Å | NPT（1 bar）的 r12 / Å |
| --- | --- | --- | --- | --- |
| local-dev | `c71ef819ab` | 1 | 0.9998189423194948 | 0.9999999818925946 |
| stable_22Jul2025 | `c7ae612a94` | 1 | 0.9998189423194948 | 0.9999999818925946 |
| stable_30Sep2026 | `8de817dd79` | 1 | 0.9998189423194948 | 0.9999999818925946 |

初始 r12 均为 1 Å。三种坐标读取方式均复现同一结果：直接用 x/y/z、用
xs/ys/zs 和**当帧盒原点/盒长**重建，以及直接用 xu/yu/zu。所有 image flags
均为零，无跨周期边界；坐标重建误差最大为 1.78e-15 Å。输出保留 17 位有效数字。
这里没有将分数坐标的差直接当作真实距离，也没有用旧盒长换算新帧。

在三种版本中还观察到：

- 无实际盒变化的 NPT 对照保持 r12=1 Å；NPH 也复现缩放。
- `rigid/npt` 与 `rigid/npt/small` 有同样变化；非零平动速度的对照也复现。
- 刚体 NPT 的内部距离比例与 `sqrt(L_new/L_old)` 相符，误差约 1e-15 Å。
  结合源码的 `remap -> set_xv -> remap`，支持末次原子映射导致该现象的解释。
- `rigid/nve/small` 后定义空组 `fix npt`，r12 变为 0.9991854985561108 Å，
  对应整次盒长缩放；反向定义顺序被程序拒绝。

原始帧和日志见本机 `results/<版本>/<case>/`；完整观察快照见
[observed_reference_behavior.json](observed_reference_behavior.json)。

## 对本项目的决策

用户已明确：**以 GPUMD 算法的物理正确性为验收标准，不要求逐步复制 LAMMPS。**
本次未修改 GPUMD 生产算法，不把上述参考行为移植进来。
本观察只说明指定测试中的参考坐标行为，不推断所有 LAMMPS 模式均有问题，
也不直接证明任一实现的长期 NPT 分布正确或错误。

本项目后续应验证约束、步长收敛和系综统计。现有解析子步与短测试通过，
并不能自动证明完整耦合积分及长期采样正确。
